# 미디어 콘텐츠 준비

`GeminiResult.webp`에서 변수, 반복문, 함수 패널을 잘라 각 단원 삽화로 사용합니다. 잘라낸 파일은 페이지에서 바로 불러옵니다.

- `variables-illustration.png`: 변수 단원 삽화
- `loops-illustration.png`: 반복문 단원 삽화
- `functions-illustration.png`: 함수 단원 삽화

아래 미디어 파일들은 콘텐츠 제작 시 추가할 수 있도록 이름과 위치를 정해 두었습니다.

- `code-loop.mp4`: 표지용 코드 루프 영상. 짧은 무음 루프, 가로형(16:9), 자막을 포함하면 좋습니다.
- `code-loop-poster.jpg`: 영상 재생 전 표지 이미지.
- `bgm.mp3`: 표지와 학습 화면에서 반복 재생할 배경음악. BGM 버튼을 누르면 재생됩니다.
- `narration-1.mp3`: 변수 화면 내레이션.
- `narration-2.mp3`: for 반복 화면 내레이션.
- `narration-3.mp3`: 함수 화면 내레이션.

내레이션 원고는 각 개념 화면의 `data-narration` 속성에 준비되어 있습니다. 현재는 브라우저 한국어 음성 합성을 사용하며, 녹음 파일이 준비되면 해당 화면의 재생 방식에 연결할 수 있습니다. 설명 한 줄은 모두 30자 이내로 작성했습니다.
